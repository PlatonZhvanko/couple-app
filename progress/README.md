# Прогресс разработки

Здесь ведётся учёт того, насколько готово приложение «Вдвоём».

- `progress.json` — единственный источник правды: разделы и их задачи.
- `dashboard.html` — красивая страница с персонажем Рыжиком, опубликована как Artifact:
  https://claude.ai/artifact/8R6eqDe8JH782Daq7yVGDK

## Как считается процент

У задачи `status`: `done` (готово, 1), `doing` (в работе, ½), `todo` (впереди, 0).
Необязательный `weight` (по умолчанию 1) делает большую задачу весомее.
Процент раздела = сумма очков / сумма весов. Процент всего приложения считается так же
по всем задачам всех разделов.

Цвет: белый до 10%, красный до 20%, оранжевый до 45%, жёлтый до 60%, лайм до 85%,
зелёный до 100%. Настроение Рыжика меняется вместе с цветом.

## Правило для каждой ветки (обязательно)

1. Когда задача сделана или начата, поменяйте её `status` в `progress.json` и дату `updated`.
2. Когда владелец придумывает новую функцию, сразу добавьте её задачей в нужный раздел.
   Новый раздел = новый объект в `areas` (`id`, `title`, `emoji`, `tasks`).
3. Обновите страницу: опубликуйте Artifact с `url` выше, `file_path` = `progress/dashboard.html`
   и `files` = `{"progress.json": "progress/progress.json"}` (сначала прочитайте Artifact).
4. Изменения `progress.json` коммитьте вместе со своей работой.
