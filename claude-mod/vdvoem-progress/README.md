# Мини-панель прогресса «Вдвоём» для Claude Code

Маленькая строка над полем ввода в Claude Code, которая всегда показывает, насколько готово
приложение «Вдвоём». Видна в каждой сессии, в любой папке, в терминале и в приложении Claude.

```
(ง •_•)ง Вдвоём 25% ███░░░░░░░ Рыжик засучил рукава  ▸ разделы
```

- **Свёрнуто (по умолчанию):** Рыжик с настроением, общий процент и шкала нужного цвета.
- **«▸ разделы»** (или клавиша `p`, когда панель в фокусе): шкала по каждому разделу.
- **«✓ все задачи»** или команда `/progress`: боковая панель со всеми задачами
  (✓ готово, … в работе, ○ впереди).
- **«↻ обновить»**: перечитать прогресс сразу. Сам обновляется раз в 5 минут и после ответов Claude.

Цвета: белый до 10%, красный до 20%, оранжевый до 45%, жёлтый до 60%, лайм до 85%, зелёный до 100%.

## Откуда берутся данные

Файл `progress/progress.json` из приватного репозитория `PlatonZhvanko/couple-app` читается
через GitHub CLI (`gh`), поэтому `gh` должен быть установлен и вошёл в GitHub. Если открыть
Claude Code в папке с клоном репозитория, а `gh` недоступен, файл читается с диска.
Большой трекер с Рыжиком: https://claude.ai/artifact/8R6eqDe8JH782Daq7yVGDK

## Установка на Mac (один раз)

```
brew install gh
gh auth login
gh auth setup-git
claude plugin install vdvoem-progress --marketplace PlatonZhvanko/couple-app
```

Потом перезапустите Claude Code. Обновить панель до новой версии:
`claude plugin update vdvoem-progress@vdvoem`.
