# Раздел «Клиенты»: спецификация

Короткое описание того, что делает раздел. Решения ниже приняты по умолчанию,
владелец может поменять любое.

## Чьи клиенты

- Вкладка есть у обоих. У каждого свой список клиентов и свои записи
  (поле `member` = кто вошёл). Партнёр чужих клиентов не видит.
- Вид услуг не важен: подходит для любой работы по записи (мастер, тренер, репетитор).

## Клиент

- Имя (обязательно), телефон, заметки.
- Кнопки: позвонить, написать в WhatsApp, SMS.
- История визитов, сколько всего визитов и сколько заработано на клиенте.

## Запись

- Клиент, услуга (текст, с подсказками из прошлых записей), дата и время,
  длительность (по умолчанию 60 минут), цена, заметка.
- Статус: запланирована, пришёл, не пришёл, отменена.
  Прошедшая запланированная запись помечается «Отметить результат».
- Новая запись создаётся из расписания или из карточки клиента.
  Если такого клиента ещё нет, его можно создать прямо в форме записи.
- Предупреждение, если запись пересекается по времени с другой.

## Экраны

1. **Расписание**: ближайшие записи по дням (сегодня, завтра, дальше),
   переключатель «Прошедшие».
2. **Клиенты**: список с поиском, карточка клиента.
3. **Итоги**: выбор месяца; заработано (записи «пришёл»), ожидается
   (запланированные), число визитов, неявки и отмены, популярные услуги.

## Напоминания

- Локальное уведомление на телефоне за выбранное время до записи
  (выкл, 15 мин, 30 мин, 1 час, 2 часа, за день). Бесплатно, без сервера.
- Клиенту напоминание не отправляется автоматически (это платно).
  В записи есть кнопка «Напомнить клиенту»: открывает WhatsApp или SMS
  с готовым текстом.

## Деньги

- Валюта по настройкам телефона. Заработок = сумма цен записей со статусом «пришёл».

## Синхронизация

- `clients.client` и `clients.appointment` в общей таблице `records`.
- Запись ссылается на клиента по `syncID` (без связей SwiftData, так проще синхронизировать).

## Календарь

- Записи клиентов (кроме отменённых и удалённых) видны в календаре «Планера»
  через `Feature(calendarItems:)` (`ClientsCalendar.swift`), только хозяину записи.
  Править их можно только в разделе «Клиенты».

## Пока не делаем

- Каталог услуг с ценами, предоплата и долги, фото работ, онлайн-запись клиентами.
