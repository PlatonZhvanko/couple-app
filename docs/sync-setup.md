# Как настроить аккаунты и синхронизацию

В приложении два аккаунта: ваш (владелец) и партнёра. Каждый входит один раз
по почте и паролю, дальше телефон помнит вход. Данные синхронизируются между
телефонами через бесплатный сервер [Supabase](https://supabase.com).

Пока сервер не настроен, на экране входа можно нажать **«Попробовать без сервера»**:
приложение заработает, но данные будут только на этом телефоне.

Настраивается один раз, примерно 10 минут.

## 1. Создать проект в Supabase

1. Зайти на https://supabase.com/dashboard и зарегистрироваться (можно через GitHub).
2. Нажать **New project**. Название любое, например `couple-app`.
   Регион: ближайший (например, Frankfurt). Пароль базы сохранить, но в приложении он не нужен.
3. Подождать пару минут, пока проект создастся.

## 2. Создать таблицы

1. Слева открыть **SQL Editor** → **New query**.
2. Скопировать весь файл [`supabase-setup.sql`](supabase-setup.sql), вставить и нажать **Run**.
   Должно появиться `Success`.

## 3. Создать два аккаунта (для вас и для партнёра)

1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Ввести почту и пароль, поставить галочку **Auto Confirm User**. Повторить для второго человека.
3. Снова открыть **SQL Editor** и выполнить (подставив свои почты):

```sql
with c as (insert into public.couples default values returning id)
insert into public.couple_members (user_id, couple_id, role, display_name)
select u.id, c.id,
       case when u.email = 'я@example.com' then 'owner' else 'partner' end,
       case when u.email = 'я@example.com' then 'Моё имя' else 'Её имя' end
from auth.users u, c
where u.email in ('я@example.com', 'она@example.com');
```

Так сервер узнает, что вы пара, кто из вас кто (`owner` — владелец, `partner` — партнёр)
и как вас зовут. Имя потом можно поменять в приложении: **Настройки → Профиль**.

## 4. Войти в приложении (на каждом телефоне)

1. В Supabase открыть **Project Settings** → **API** (или **Data API** / **API Keys**).
   Нужны два значения: **Project URL** и ключ **anon public**.
2. Открыть приложение. На экране входа вставить адрес и ключ, ввести свою почту
   и пароль из шага 3 и нажать **Войти**. Больше вход не понадобится.
   (Если прислать адрес и ключ Claude, он «зашьёт» их в приложение, и тогда
   на телефонах нужно будет вводить только почту и пароль.)
3. Проверить: **Настройки** → **Проверка синхронизации**. Добавить заметку на одном
   телефоне, на втором потянуть список вниз. Заметка должна появиться.

## Что важно знать

- **Бесплатно.** Бесплатного тарифа Supabase хватит с огромным запасом.
- **Засыпание.** Если неделю никто не открывает приложение, Supabase ставит проект
  на паузу. Данные не пропадают: нужно зайти в Supabase и нажать **Restore project**.
  Пока проект на паузе, приложение продолжает работать, а синхронизируется после восстановления.
- **Офлайн.** Всё сохраняется сначала на телефоне. Без интернета приложение работает,
  данные уйдут на сервер, когда появится сеть.
- **Конфликты.** Если одну и ту же запись поменяли на двух телефонах, остаётся
  более позднее изменение.
