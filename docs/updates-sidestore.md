# Обновления без провода (бесплатно)

Адрес источника для SideStore: `https://raw.githubusercontent.com/PlatonZhvanko/couple-app/sidestore/source.json`

Схема: GitHub сам собирает приложение (`.github/workflows/build-ipa.yml`) → кладёт `Vdvoem.ipa` и `source.json`
в релиз `latest` → SideStore на телефоне видит новую версию, скачивает и ставит по воздуху.

Ограничения (честно):
- Бесплатный Apple ID: подпись живёт 7 дней, SideStore продлевает её сам (телефон должен иногда быть в Wi-Fi). Максимум 3 приложения на Apple ID.
- Первую настройку SideStore делают один раз через Mac (файл сопряжения). Дальше Mac не нужен.
- Чтобы SideStore мог скачать IPA без входа в GitHub, репозиторий (или отдельный репозиторий для релизов) должен быть публичным.
  Для приватного репозитория: IPA лежит в Actions → Artifacts, скачивается вручную.
- Приватные минуты GitHub: macOS считается ×10 (≈200 минут/мес на бесплатном тарифе). Публичный репозиторий — без лимита.
- Данные после обновления сохраняются, если Bundle ID тот же (`com.couple.vdvoem`).
