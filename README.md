# Вдвоём

Личное приложение для iPhone на двоих: планер, питание, сон, настроение,
клиенты, авто и всё остальное, что понадобится. Написано на SwiftUI.

## Как запустить на Mac

Нужно: Mac с **Xcode 16 или новее** (бесплатно в App Store).

1. Скачать проект. Проще всего через Xcode: **Xcode → Integrate → Clone…**
   (в старых версиях **Source Control → Clone…**), вставить адрес
   `https://github.com/PlatonZhvanko/couple-app` и войти в GitHub, если попросит.
   Либо в Терминале: `git clone https://github.com/PlatonZhvanko/couple-app`.
2. Открыть файл **`CoupleApp.xcodeproj`** двойным щелчком.
3. Вверху окна Xcode выбрать симулятор, например **iPhone 16**, и нажать ▶︎ (**Cmd+R**).
   Через минуту откроется приложение с вкладками.

## Как поставить на свой iPhone (бесплатно)

1. Подключить iPhone к Mac кабелем, на телефоне нажать «Доверять этому компьютеру».
2. В Xcode: **Xcode → Settings → Accounts → +** → **Apple ID**, войти своим Apple ID.
3. Слева в Xcode нажать на синий значок **CoupleApp** → вкладка **Signing & Capabilities**.
   В поле **Team** выбрать свою команду (будет «Ваше имя (Personal Team)»).
   Если Xcode пишет, что Bundle Identifier занят, поменять его на любой свой,
   например `com.ваше-имя.vdvoem`.
4. Вверху окна выбрать свой iPhone вместо симулятора и нажать ▶︎.
5. На iPhone при первом запуске: **Настройки → Основные → VPN и управление устройством**
   → выбрать свой Apple ID → **Доверять**. Также, если попросит, включить
   **Настройки → Конфиденциальность и безопасность → Режим разработчика**.

Ограничение бесплатного Apple ID: приложение работает 7 дней, потом его нужно
снова запустить из Xcode (данные при этом сохраняются).

## Аккаунты и синхронизация

У каждого свой аккаунт: вход один раз по почте и паролю, дальше телефон помнит.
Данные синхронизируются между телефонами. Как настроить:
[docs/sync-setup.md](docs/sync-setup.md).

Пока сервер не настроен, на экране входа можно нажать «Попробовать без сервера».
